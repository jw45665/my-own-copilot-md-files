# Corporate Gray

Minimalistisches Grau-Schema für Business-Anwendungen.

## Sf-taugliche Struktur

```css
[data-theme="corporate-gray"] {
  --bg-primary: #ffffff;
  --bg-secondary: #f9fafb;
  --bg-accent: #f3f4f6;
  --text-primary: #111827;
  --text-secondary: #6b7280;
  --accent-color: #4b5563;
  --navbar-bg: #1f2937;
  --navbar-text: #ffffff;
  --header-text: #ffffff;
  --border-color: #e5e7eb;
}
```

## Typografie

- **Überschriften**: DejaVu Sans Bold
- **Fließtext**: DejaVu Sans

## Anwendungsfälle

Admin Dashboards, Enterprise Software, Analytics Tools

## Stimmung

Neutral, fokussiert, professionell, minimalistisch
