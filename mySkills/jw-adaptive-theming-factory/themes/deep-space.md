# Deep Space

```css
[data-theme="deep-space"] {
  --bg-primary: #000000;
  --bg-secondary: #0a0a0a;
  --bg-accent: #1a1a1a;
  --text-primary: #ffffff;
  --text-secondary: #a3a3a3;
  --accent-color: #8b5cf6;
  --navbar-bg: #7c3aed;
  --navbar-text: #ffffff;
  --header-text: #ffffff;
  --border-color: rgba(255,255,255,0.08);
}
```
