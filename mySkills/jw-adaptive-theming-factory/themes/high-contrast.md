# High Contrast

Maximaler Kontrast für Accessibility.

## Sf-taugliche Struktur

```css
[data-theme="high-contrast"] {
  --bg-primary: #ffffff;
  --bg-secondary: #f3f4f6;
  --bg-accent: #e5e7eb;
  --text-primary: #000000;
  --text-secondary: #1f2937;
  --accent-color: #0000ff;
  --navbar-bg: #000000;
  --navbar-text: #ffffff;
  --header-text: #ffffff;
  --border-color: #000000;
}
```

## Typografie

- **Überschriften**: DejaVu Sans Bold
- **Fließtext**: DejaVu Sans

## Anwendungsfälle

Accessibility, Government, Education
