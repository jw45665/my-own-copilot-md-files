# Red

Warmes rotes Theme mit hellem Hintergrund.

## Sf-taugliche Struktur

```css
[data-theme="red"] {
  --bg-primary: #ffffff;
  --bg-secondary: #fff5f5;
  --bg-accent: #fee2e2;
  --text-primary: #0f1724;
  --text-secondary: #374151;
  --accent-color: #dc2626;
  --navbar-bg: #dc2626;
  --navbar-text: #ffffff;
  --header-text: #ffffff;
  --border-color: #fca5a5;
}
```

## Typografie

- **Überschriften**: DejaVu Sans Bold
- **Fließtext**: DejaVu Sans

## Kontrast-Ratio

- Dunkelblau auf Weiß: 17:1 (WCAG AAA ✓)
- Rot auf Rosa: 7.2:1 (WCAG AA ✓)

## Anwendungsfälle

Akzentstarke Oberflächen, Warnbereiche und aufmerksamkeitsstarke Kampagnen.

## Stimmung

Energisch, leidenschaftlich, warm, aufmerksamkeitsstark
