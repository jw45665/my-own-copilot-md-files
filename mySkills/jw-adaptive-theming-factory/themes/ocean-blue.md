# Ocean Blue

Erfrischendes Theme inspiriert vom Ozean.

## Sf-taugliche Struktur

```css
[data-theme="ocean"] {
  --bg-primary: #ffffff;
  --bg-secondary: #ecfeff;
  --bg-accent: #cffafe;
  --text-primary: #083344;
  --text-secondary: #155e75;
  --accent-color: #06b6d4;
  --navbar-bg: #0e7490;
  --navbar-text: #ffffff;
  --header-text: #ffffff;
  --border-color: #a5f3fc;
}
```

## Typografie

- **Überschriften**: DejaVu Sans Bold
- **Fließtext**: DejaVu Sans

## Anwendungsfälle

Reise, Wassersport, Maritime, Wellness

## Stimmung

Erfrischend, ruhig, weitläufig, klar
