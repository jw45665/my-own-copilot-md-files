# Dark

Dunkles Theme mit mittlerem Kontrast für angenehmes Lesen.

## Sf-taugliche Struktur

```css
[data-theme="dark"] {
  --bg-primary: #212529;
  --bg-secondary: #343a40;
  --bg-accent: #495057;
  --text-primary: #ffffff;
  --text-secondary: #adb5bd;
  --accent-color: #dc3545;
  --navbar-bg: #343a40;
  --navbar-text: #ffffff;
  --header-text: #ffffff;
  --border-color: #495057;
}
```

## Typografie

- **Überschriften**: DejaVu Sans Bold
- **Fließtext**: DejaVu Sans

## Kontrast-Ratio

- Weiß auf Dunkelgrau: 15.8:1 (WCAG AAA ✓)

## Anwendungsfälle

Augenschonende Anwendungen, Analyseoberflächen und dunkle Dashboards.

## Stimmung

Modern, augenschonend, elegant, Tech
